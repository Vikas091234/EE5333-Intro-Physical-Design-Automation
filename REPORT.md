# EE5333 – Project Report / Portfolio Summary

## Overview

This repository contains selected implementations developed for EE5333 – Introduction to Physical Design Automation at IIT Madras. The work covers optimization and algorithms used in VLSI physical design, together with a course project focused on detailed routing.

## Implemented coursework

- **ILP formulations:** graph optimization problems including Minimum Dominating Set and Maximum-Weight Independent Set.
- **Partitioning:** Fiduccia–Mattheyses based graph partitioning.
- **Floorplanning:** algorithmic floorplanning using representation-based methods.
- **SAT:** Boolean satisfiability problem solving and CNF-based experimentation.
- **Placement:** placement-related optimization and implementation.
- **Branch and Bound:** integer programming optimization using LP relaxation and recursive branching.

## Course project – Detailed Routing

The course project works with standard physical-design data formats and implements a detailed-routing workflow. It includes: 

1. Reading LEF/DEF design information and routing guides.
2. Generating routed DEF solutions.
3. Checking connectivity of routed nets.
4. Performing spacing DRC checks.
5. Evaluating generated routing solutions on benchmark circuits.

### Technologies / concepts

`Python` · `Integer Linear Programming` · `Graph Algorithms` · `SAT` · `Floorplanning` · `Placement` · `VLSI Physical Design` · `LEF/DEF` · `Detailed Routing` · `DRC`

## Portfolio relevance

The course project is the primary portfolio component of this repository because it demonstrates implementation of a physical-design algorithm around real design interchange formats and benchmark data, rather than only solving isolated coursework problems.
