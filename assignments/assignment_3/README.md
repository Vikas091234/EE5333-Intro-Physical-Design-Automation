# Assignment 3 – Floorplanning using Sequence Pairs

## Course

EE5333 – Introduction to Physical Design Automation

## Objective

This assignment implements a floorplanning algorithm using
sequence pairs and simulated annealing.

Given a set of modules with specified areas and allowed aspect
ratios, the objective is to find a floorplan that minimizes the
area of the smallest rectangle enclosing all modules.

## Approach

The implementation consists of three main components:

1. Sequence-pair representation
2. Coordinate and floorplan evaluation
3. Simulated annealing optimization

### Sequence Pair

Each floorplan is represented using two permutations:

- Positive sequence
- Negative sequence

The relative ordering of two modules in these sequences determines
whether one module is placed to the left/right or above/below the
other.

### Horizontal and Vertical Constraint Graphs

The sequence pair is converted into:

- Horizontal Constraint Graph (HCG)
- Vertical Constraint Graph (VCG)

Longest-path calculations on these graphs determine the coordinates
and overall dimensions of the floorplan.

### Simulated Annealing

Simulated annealing is used to search for a good sequence pair.

At each iteration, a new solution is generated by one of the
following perturbations:

- Swapping two modules in the positive sequence
- Swapping two modules in both sequences
- Changing the aspect ratio of a module

Solutions that improve the floorplan are accepted, while some
worse solutions are also accepted at higher temperatures to avoid
getting trapped in local minima.
